# ── STEP 1: Connect Power BI to Databricks ──────────────────

1. Open Power BI Desktop
2. Click Get Data → Search "Azure Databricks" → Select it
3. Fill in:
     Server:    <your-workspace>.azuredatabricks.net
     HTTP Path: copy from Databricks > SQL Warehouses > Connection Details
     Mode:      DirectQuery
4. Click OK → Sign in with Azure credentials


# ── STEP 2: Import Tables + Define Relationships ────────────

Tables to import:
  - fact_anomaly_scores
  - fact_sales
  - dim_product
  - dim_store
  - dim_date

Relationships (all Many to One, Single direction):
  fact_anomaly_scores.product_id  →  dim_product.product_id
  fact_anomaly_scores.store_id    →  dim_store.store_id
  fact_anomaly_scores.date        →  dim_date.date
  fact_sales.product_id           →  dim_product.product_id
  fact_sales.store_id             →  dim_store.store_id
  fact_sales.date                 →  dim_date.date


# ── STEP 3: DAX Measures ────────────────────────────────────
# Create these in fact_anomaly_scores table
# Home → New Measure → paste formula → Enter

# 3.1 Total Anomalies Today
Total Anomalies Today =
CALCULATE(
    COUNTROWS(fact_anomaly_scores),
    fact_anomaly_scores[is_anomaly] = TRUE(),
    fact_anomaly_scores[date] = TODAY()
)

# 3.2 Anomaly Rate %
Anomaly Rate % =
DIVIDE(
    CALCULATE(
        COUNTROWS(fact_anomaly_scores),
        fact_anomaly_scores[is_anomaly] = TRUE()
    ),
    COUNTROWS(fact_anomaly_scores),
    0
) * 100

# 3.3 Sales vs Expected
Sales vs Expected =
SUM(fact_anomaly_scores[total_quantity])
- SUM(fact_anomaly_scores[expected_value])

# 3.4 Avg Anomaly Score
Avg Anomaly Score =
CALCULATE(
    AVERAGE(fact_anomaly_scores[anomaly_score]),
    fact_anomaly_scores[is_anomaly] = TRUE()
)

# 3.5 Last Refreshed (place top-right on every page)
Last Refreshed =
"Data current as of: " & FORMAT(NOW(), "DD MMM YYYY HH:MM")

# --- Main Anomaly Table (middle) ---
Visual type: Table
Columns:
  dim_product[product_name]
  dim_product[category]
  dim_store[store_name]
  fact_anomaly_scores[hour]
  fact_anomaly_scores[total_quantity]
  fact_anomaly_scores[expected_value]
  fact_anomaly_scores[anomaly_score]
  fact_anomaly_scores[severity]

Filters:
  fact_anomaly_scores[is_anomaly] = TRUE
  fact_anomaly_scores[date] = TODAY()

Sort by: anomaly_score descending

Purpose:
  Managers see a ranked action list — highest priority anomaly
  at the top. Red rows need immediate attention.

# --- Anomalies by Department Bar Chart (bottom) ---
Visual type: Bar chart (clustered)
X-axis: dim_product[category]
Y-axis: Count of fact_anomaly_scores[is_anomaly]
Filter: is_anomaly = TRUE, date = TODAY()
Purpose: Which department has the most unusual activity?


# ── STEP 5: Page 2 — Product Deep Dive ─────────────────────
# Drill into any single product to see exactly what happened.

# --- Slicers (top) ---
Slicer 1: dim_product[product_name]
Slicer 2: dim_store[store_name]
Slicer 3: dim_date[date]

# --- Actual vs Expected Line Chart (main visual) ---
Visual type: Line chart
X-axis: fact_anomaly_scores[hour]
Lines:
  SUM(fact_anomaly_scores[total_quantity])   → label: Actual Sales (solid)
  SUM(fact_anomaly_scores[expected_value])   → label: Expected (solid grey)
  SUM(fact_anomaly_scores[upper_bound])      → label: Upper Bound (dashed)
  SUM(fact_anomaly_scores[lower_bound])      → label: Lower Bound (dashed)

What to look for:
  When the Actual line crosses above the Upper Bound dashed line
  → that hour is your anomaly.
  When Actual drops below Lower Bound
  → unexpected drop (empty shelf / pricing issue).
